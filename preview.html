Qué hace

  • Se sienta a teclear en la laptop cuando trabajas.
  • Duerme (z z z) si no usas la PC; audífonos si hay música.
  • Reacciona si la acarician, la mueven o la sueltan.
  • Habla con un modelo local (Ollama), con memoria de la charla.
  • abre youtube, busca gatos, volumen, captura… y ! orden para el agente.

Instalar

git clone <repo> && cd clawd-desktop && ./install.sh

El instalador abre un menú: comprueba dependencias, detecta/instala Ollama, te recomienda modelo según tu RAM y la deja corriendo.
